## Contract 1: SKILL.md Frontmatter

Every `SKILL.md` file under `.agent/skills/*/` **must** include this frontmatter block:

```yaml
---
name: <slug>          # Required. Lowercase, hyphenated. Matches parent folder name.
description: |        # Required. 2-4 sentences. Must include trigger keywords.
  Use when <scenario>.
  Triggers on: "<kw1>", "<kw2>", "<kw3>".
---
```

**Validation rules:**
- `name` must match the folder name exactly.
- `description` must contain at least one `Triggers on:` clause.
- No additional frontmatter keys are permitted (they are ignored by the runtime).

**Body sections (recommended order):**
1. `## When to Use` — required
2. `## Workflow` or `## Steps` — required
3. `## Template` — optional, include code examples
4. `## Constraints` — required (what NOT to do)
5. `## Examples` — optional

## Contract 2: Rule File Frontmatter

Every rule file under `.agent/rules/` **must** include:

```yaml
---
description: "<one-line summary>."   # Required. Ends with period.
activation: always | glob            # Required.
glob: "**/*.{ext}"                   # Required when activation is "glob". Omit when "always".
---
```

**Validation rules:**
- `activation: always` → no `glob` key.
- `activation: glob` → `glob` key required, must be a valid glob pattern.
- Files named `01-*` → should use `activation: always`.
- Files named `02-*` through `09-*` → may use either activation mode.

## Contract 3: Setup Script Interface

Both `setup.sh` and `setup-antigravity-template.ps1` must respect this interface:

**Pre-conditions:**
- Script is run from the root of a **new, empty target project directory**.
- The script is passed (or auto-detects) the path to the `anti-gravity-template` repo.

**Post-conditions:**
- `GEMINI.md` exists at target root.
- `AGENTS.md` exists at target root.
- `.agent/rules/` contains all three committed rule files.
- `.agent/skills/` contains all committed skill folders (each with `SKILL.md`).
- `docs/ADDING_SKILLS.md` exists.
- `.gitignore` is present.

**Anti-conditions (must NOT happen):**
- No inline file content in the script body (all content sourced from committed files).
- Script must not overwrite existing files without `--force` flag.
