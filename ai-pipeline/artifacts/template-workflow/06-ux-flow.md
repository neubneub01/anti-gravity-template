## Flow 1: New Project Bootstrap

```
Developer clones anti-gravity-template
         │
         ▼
Reads README.md
  ├─ Understands structure
  └─ Runs setup.sh <target-dir>   (Linux/macOS)
     OR setup-antigravity-template.ps1  (Windows)
         │
         ▼
Opens target project in AI coding tool (Antigravity/Cursor/Claude Code)
         │
         ▼
Fills in .agent/rules/01-project-context.md
  └─ Checklist in file confirms all sections are complete
         │
         ▼
Deletes unused skills (.agent/skills/)
         │
         ▼
AI assistant now has full context → productive immediately
```

**Pain points identified:**
- User must remember to delete unused skills manually; no guided cleanup step.
- `01-project-context.md` has no visual indicator that it's incomplete (beyond comments).

**Improvement**: The setup checklist in `01-project-context.md` addresses the second pain point directly.
