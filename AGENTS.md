# Cross-Tool Agent Rules

> Shared rules read by Antigravity, Cursor, and Claude Code.
> Antigravity-specific overrides go in GEMINI.md.

## General

- Respond concisely. No filler text.
- When uncertain, ask before assuming.
- Always check for existing patterns in the codebase before introducing new ones.

## Python Conventions

- Python 3.11+ minimum.
- Use `pathlib.Path` over `os.path`.
- Use `httpx` over `requests` for async HTTP.
- Prefer f-strings over `.format()`.
- Use `logging` module, never `print()` for diagnostics.

## TypeScript Conventions

- Strict mode enabled. No implicit any.
- Prefer `const` over `let`. Never `var`.
- Use `zod` for runtime validation on the frontend.

## Infrastructure

- Docker Compose for local dev. Multi-stage Dockerfiles for prod.
- Environment variables via `.env` files (never committed).
- All services must have health check endpoints.

## Documentation

- Every project must have a README.md with: purpose, setup, architecture, and contributing sections.
- API endpoints must be documented via OpenAPI (auto-generated by FastAPI).
